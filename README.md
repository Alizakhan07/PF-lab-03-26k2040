## Introduction

This repository contains the solution and documentation for Lab 03 of the Programming Fundamentals course. The lab focuses on strengthening core C programming concepts through hands-on practice with control structures, functions, and data handling.

## Objectives

1. Understand and apply conditional statements in C.
2. Practice using loops (`for`, `while`, `do-while`) to solve repetitive tasks.
3. Learn how to write and call user-defined functions.
4. Work with arrays and understand memory allocation basics.
5. Improve debugging and problem-solving skills through practical exercises.

## Topics Covered

- Conditional statements (`if`, `else if`, `else`, `switch`)
- Loops and iteration
- Functions and parameter passing
- Arrays and strings
- Basic input/output using `scanf` and `printf`

> "The only way to learn a new programming language is by writing programs in it." — Dennis Ritchie

As an example, printing a value to the console in C is as simple as using `printf("Hello, World!\n");`.
